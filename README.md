# Tooth Tiles (牙了个牙)

> Zero-dependency HTML5 dental-themed 3-match tile puzzle game with a custom 3-zone level generator, Monte Carlo solvability simulator (`simulate.js`), and interactive oral health quizzes.

# 牙了个牙

牙齿主题的堆叠三消小游戏（「羊了个羊」类玩法）：点击最上层方块放入七格槽，凑齐 3 个相同即消除，清空全部方块过关。**只有两关**（第 1 关教学 + 第 2 关正式），进度自动保存。

难度设计仿照原版日常关的**三区结构**（布局自研，不搬官方每天的地图文件）：中间是半格错位的交叉重堆叠（难度主要在这里），左右是悬空辅助牌（单列，残局缓冲用），底部两摞盲盒只能盲点。第 2 关 **13 种图案**。生成算法思路参考开源项目 [yulegeyu](https://github.com/liyupi/yulegeyu) 与公开的关卡数据格式解析。

纯网页实现（零依赖、无需安装），手机触屏和电脑鼠标都能玩。

## 怎么打开

- 双击 `index.html` 直接玩；
- 或本地服务：

```bash
cd 牙了个牙
python3 -m http.server 8643
```

打开 http://localhost:8643

## 道具（每关各 1 次）

- ↩️ 撤销：把最近放进槽里的方块放回原位（盲点的暗牌与已消除的不能撤销）
- 🔀 洗牌：位置不动，重新打乱所有剩余方块（含暗牌堆）的图案
- 📤 移出：把槽里前 3 个方块移回棋盘底部

## 科普视频答题（护牙小课堂）

看科普视频 + 答对护牙知识题可以赢奖励：

- **🎬 学知识按钮**：答题成功三种道具各 +1（每关限 2 次）。
- **槽满输了以后**：看视频答题可以复活——槽里的方块全部退回棋盘底部继续玩（每关限一次）。

视频目前是占位画面（3 秒倒计时）。**把真实科普视频命名为 `quiz.mp4` 放进 `assets/` 文件夹即自动替换**，播完自动出题，不用改代码。

## 换美术

见 `美术素材清单.md`，PNG 放进 `assets/` 即自动替换，缺图用表情符号占位。

## 测试参数

- `?level=5`：直接进第 5 关
- `?level=1&demo=1`：自动演示一次三消（截图用）
- `?quiz=1`：直接打开答题界面；`?quiz=q` 跳过视频直接出题；再加 `&qa=right` / `&qa=wrong` 自动作答
